# Esercitazione sui file CSV

Progetto Java realizzato per esercitarsi con la lettura e la scrittura di file CSV.

Il programma simula un semplice database relazionale utilizzando diversi file CSV collegati tramite ID.

## Struttura dei dati

Il progetto utilizza i seguenti file:

- `nomi.csv` - contiene ID e nome
- `cognome.csv` - contiene ID e cognome
- `azienda.csv` - contiene ID e azienda PCTO
- `vacanze.csv` - contiene ID e luogo di vacanza
- `studenti.csv` - contiene gli ID che collegano i dati dello studente
